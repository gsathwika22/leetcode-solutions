## Solution

```java
class Solution {
    public List<String> summaryRanges(int[] nums) {
        
        ArrayList<String> l=new ArrayList<>();
       int i=0;
       while(i<nums.length)
       {

        int start=nums[i];
        while(i+1<nums.length && nums[i+1]==nums[i]+1)
        i++;
        if(start!=nums[i])
        {
            l.add(start+"->" +nums[i]);  
        }
        else
        l.add(String.valueOf(nums[i]));
        i++;
       }
        return l;
        
    }
}
```
