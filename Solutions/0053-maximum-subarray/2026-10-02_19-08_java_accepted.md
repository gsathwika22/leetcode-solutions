## Solution

```java
class Solution {
    public int maxSubArray(int[] nums) {
       int s=0;
       int m=nums[0];
       for(int r=0;r<nums.length;r++){
        if(s<0)
        {
            s=0;
        }
        s+=nums[r];
        m=Math.max(m,s);
       }
       return m;
    }
}
```
