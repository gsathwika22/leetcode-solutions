## Solution

```java
class Solution {
    public int maxSubArray(int[] nums) {
       int s=0;
       int l=0;
       int m=nums[0];
       for(int r=0;r<nums.length;r++){
       if(s<0)
       {
       s=0;
       l=r;
       }
       s+=nums[r];
       
       if(s>m)
       m=s;
       }
       return m;
    }
}
```
