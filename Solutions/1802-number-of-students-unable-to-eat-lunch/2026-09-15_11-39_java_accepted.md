## Solution

```java
class Solution {
    public int countStudents(int[] students, int[] sandwiches) {
        int[] c=new int[2];

        for(int s:students)
        c[s]++;

        for(int s:sandwiches)
        {
            if(c[s]>0)
            c[s]--;
            else
            break;
        }

        return c[0]+c[1];
    }
}
```
