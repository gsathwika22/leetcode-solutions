## Solution

```java
class Solution {
    public int[] numberGame(int[] nums) {
        
        PriorityQueue<Integer> pq=new PriorityQueue<>();
        int[] arr=new int[nums.length];
        for(int i=0;i<nums.length;i++)
        {
            pq.add(nums[i]);
        }
      int j=0;
        while(pq.size()>0)
        {
        int a=pq.poll();
        int b=pq.poll();
        
        arr[j++]=b;
        arr[j++]=a;
        }
    return arr;
    }
}
```
