## Solution

```java
class Solution {
    public int sumCounts(List<Integer> nums) {
        int n=nums.size();
       int s=0;
        for(int i=0;i<n;i++)
        {
             HashSet<Integer> hs=new HashSet<>();
            for(int j=i;j<n;j++)
            {
                hs.add(nums.get(j));
                int t=hs.size();
                s+=t*t;
                // System.out.println(nums.get(j)+" ");
            }
            
        }
        

    return s;



    }
}
```
