## Solution

```java
class Solution {
    public boolean validateStackSequences(int[] pushed, int[] popped) {
        
        Stack<Integer> st=new Stack<>();
        int c=0;
        for(int i:pushed)
        {
            st.push(i);
        
    while(!st.isEmpty() && st.peek()==popped[c])
    {
       st.pop();
      c++;

    }}
    return st.isEmpty();
    }
}
```
