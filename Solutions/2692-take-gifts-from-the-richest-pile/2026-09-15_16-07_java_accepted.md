## Solution

```java
class Solution {
    public long pickGifts(int[] gifts, int k) {
        
        PriorityQueue<Integer> pq=new PriorityQueue<>(Collections.reverseOrder());

        for(int i:gifts)
        pq.add(i);

        for(int i=0;i<k;i++)
        {
            pq.add((int)Math.sqrt(pq.poll()));
           
        }
        long sum=0;
        for(int x:pq)
        sum+=x;
    return sum;
    }
}
```
