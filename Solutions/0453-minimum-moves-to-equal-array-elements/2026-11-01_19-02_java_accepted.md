## Solution

```java
class Solution {
    public int minMoves(int[] nums) {

        int min=Integer.MAX_VALUE;
        long m=0;
        for(int x:nums)
        if(x<min)
        min=x;
        for(int y:nums)
        m+=y-min;

        return (int)m;
        
    }
}
```
