## Solution

```java
class Solution {
    public String removeOuterParentheses(String s) {
        StringBuilder sb=new StringBuilder();
        int c=0;

        for(char ch:s.toCharArray())
        {
            if(ch=='(')
            {
                if(c>0)
                {
                    sb.append(ch);
                   
                }
                c++;
            }
            else
            {
                 c--;
                if(c>0)
               {
                    sb.append(ch);
                    // c--;
                }
            }
        }
        return sb.toString();
    }
}
```
