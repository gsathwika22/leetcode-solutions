## Solution

```java
class Solution {
    public int largestInteger(int[] nums, int k) {
        
        int n=nums.length;
        int[] c=new int[51];
        for(int x:nums)
        {
            c[x]++;
        }
        if(k==1)
        {
            int ans=-1;
            for(int i=0;i<=50;i++)
            {
                if(c[i]==1)
                ans=i;

            }
            return ans;
        }
        if(k==n)
        {
            int max=-1;
            for(int x:nums)
            max=Math.max(max,x);
            return max;
        }
        int ans=-1;
        if(c[nums[0]]==1) ans=Math.max(ans,nums[0]);
        if(c[nums[n-1]]==1) ans=Math.max(ans,nums[n-1]);
        
        return ans;
    }
}
```
