## Solution

```java
class Solution {
    public boolean checkValidString(String s) {
            int c=0,d=0;
            for(int i=0;i<s.length();i++)
            {
                char ch=s.charAt(i);
                if(ch=='(')
                {
                    c++;
                    d++;
                }
                else if(ch==')')
                {
                d--;
                c--;
                }
                else if(ch=='*')
                {
                    d++;
                    c--;
                }
                
            if(d<0)
             return false;
             c=Math.max(c,0);
            }
            return c==0;
    }
}
```
