## Solution

```java
class Solution {
    int mod=1000000007;
    public int distinctSubseqII(String s) {
      int t=0;
      int[] dp=new int[26];
      for(int i=0;i<s.length();i++)
      {
        int c=s.charAt(i)-97;
        int add=(t-dp[c]+mod)%mod;

        dp[c]=1+t;
        t=(dp[c]+add)%mod;
      }

        return t;
    }
}
```
