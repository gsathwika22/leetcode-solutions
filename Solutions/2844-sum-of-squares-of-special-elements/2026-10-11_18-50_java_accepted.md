## Solution

```java
class Solution {
    public int sumOfSquares(int[] nums) {
        int n=nums.length;
        int sq=0;
        List<Integer> ls=new ArrayList<>();
        for(int i=1;i<=n;i++)
        {
            if(n%i==0)
            {
               ls.add(nums[i-1]);
            }
        }
        for(int i=0;i<ls.size();i++)
        {
            sq+=Math.pow(ls.get(i),2);
        }
        return sq;
    }
}
```
