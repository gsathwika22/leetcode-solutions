## Solution

```java
class Solution {
    public int maxSubarrayLength(int[] nums, int k) {
        int l=0,c=0;
        HashMap<Integer,Integer> hm=new HashMap<>();
       
        for(int r=0;r<nums.length;r++)
        {
            int i=nums[r];
             hm.put(i,hm.getOrDefault(i,0)+1);
            while(hm.get(nums[r])>k)
            {
                int lt=nums[l];
                hm.put(lt,hm.get(lt)-1);
                l++;
            }
            c=Math.max(c,r-l+1);

        }
        return c;
    }
}
```
