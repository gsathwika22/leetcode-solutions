## Solution

```java
class Solution {
    public int minOperations(int[] nums, int x) {

        int tsum=0;
        for(int n:nums)
        {
            tsum+=n;
        }
        int t=tsum-x;
        if(t<0)
        return -1;
       int l=0,sum=0,max=-1;
       for(int r=0;r<nums.length;r++)
       {
        sum+=nums[r];
        while(sum>t && l<=r)
        {
            sum-=nums[l];
            l++;
        }
        if(sum==t)
        max=Math.max(max,r-l+1);
       } 
    return max==-1?-1:nums.length-max;
    }
}
```
