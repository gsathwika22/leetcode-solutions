## Solution

```java
class Solution {
    public int minMoves(int[] nums) {
        int min=Integer.MIN_VALUE;
  
        for(int i:nums)
        min=Math.max(min,i);

        int rs=0;
        for(int i:nums)
        rs+=(min-i);
    return rs;
    }
}
```
