## Solution

```java
class Solution {
    public int missingMultiple(int[] nums, int k) {
       Set<Integer> s=new HashSet<>();
       for(int n:nums)
       s.add(n);

       int c=k;
       while(s.contains(c))
       c+=k;

    return c;
    }
}
```
