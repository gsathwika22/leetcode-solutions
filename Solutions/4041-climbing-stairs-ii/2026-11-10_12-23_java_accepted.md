## Solution

```java
class Solution {
    public int climbStairs(int n, int[] costs) {
        long dp[]=new long[n+1];
        dp[0]=0;
        for(int j=1;j<=n;j++)
        {
            long mincost=Long.MAX_VALUE;
            for(int k=1;k<=3;k++)
            {
                int i=j-k;
                if(i>=0)
                {
                    long cost=dp[i]+costs[j-1]+(long)(j-i)*(j-i);
                    mincost=Math.min(mincost,cost);
                }
            }
            dp[j]=mincost;
        }
        return (int)dp[n];
    }
}
```
