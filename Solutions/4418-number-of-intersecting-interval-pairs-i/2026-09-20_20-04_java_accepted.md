## Solution

```java
class Solution {
    public int countIntersectingIntervals(int[][] nums)
     {
        int c=0;
        int n=nums.length;
        for(int i=0;i<n;i++)
        {
            int s1=nums[i][0];
            int e1=nums[i][1];
        for(int j=i+1;j<n;j++)
        {
            int s2=nums[j][0];
            int e2=nums[j][1];
            if(s1<=e2 && s2<=e1)
            c++;

            
        } 
        }
        return c;
    }
}
```
