## Solution

```java
class Solution {
    public int minAddToMakeValid(String s) {
       Stack<Character> st=new Stack<>();
        int ans=0;
       for(int i=0;i<s.length();i++)
       {
        char ch=s.charAt(i);
        if(ch=='(')
        st.push(ch);
        else
        {
      
            if(!st.isEmpty())
            {
              st.pop();
            }
            else
            ans++;
        }
       }
       return ans+st.size();
    }
}
```
