## Solution

```java
class Solution {
    public long[] resultArray(int[] nums, int k) {
        
        long res[]=new long[k];
        long s[]=new long[k];
        for(int v:nums)
        {
           int rem=v%k;
           long[] nxt=new long[k];
           for(int r=0;r<k;r++)
           {
            int nr=(r*rem)%k;
            nxt[nr]+=s[r];
            res[nr]+=s[r];
           }
           nxt[rem]++;
           res[rem]++;
           s=nxt;
        }
        return res;
    }
}
```
