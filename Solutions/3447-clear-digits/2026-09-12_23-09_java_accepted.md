## Solution

```java
class Solution {
    public String clearDigits(String s) {

        Stack<Character> st=new Stack<>();
        StringBuilder sb=new StringBuilder();

        for(int i=0;i<s.length();i++)
        {
            if(Character.isDigit(s.charAt(i)))
            {
                st.pop();
            }
            else
            st.push(s.charAt(i));
        }
        while(!st.isEmpty())
        {
        sb.append(st.pop());
        }
        sb.reverse();
        return sb.toString();
    }
}
```
