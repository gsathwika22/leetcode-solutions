## Solution

```java
class Solution {
    public int smallestIndex(int[] nums) {

       
     for(int i=0;i<nums.length;i++)
     {
        int t=nums[i];
        int s=0;
        
        while(t>0)
        {
            
           s+=t%10;
           t/=10;
         
        }
        if(nums[i]==0 && i==0)
        return 0;

        if(s==i)
        return i;
     }
     return -1;     
    }
}
```
