## Solution

```java
class Solution {
    public boolean judgeSquareSum(int c) {
        
        long l=0,r=(long)Math.sqrt(c),a=0;
        while(l<=r)
        {
            a=l*l+r*r;
            if(a==c)
            return  true;
            else if(a<c)
            {
                l++;
            }
            else
            r--;
        }
        return false;
    }
}
```
