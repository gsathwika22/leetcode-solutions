## Solution

```java
class Solution {
    public int maxDepth(String s) {
        Stack<Character> st=new Stack<>();
        int max=0;
        for(int i=0;i<s.length();i++)
        {
            char ch=s.charAt(i);
            if(ch=='(')
            {
                st.push(ch);
            }
            else if (ch==')')
            st.pop();

            max=Math.max(max,st.size());

        }
        return max;
    }
}
```
