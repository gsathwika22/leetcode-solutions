## Solution

```java
class Solution {
    public int reverseDegree(String s) {
        int sum=0;
        int pos=1;
        for(char c:s.toCharArray()){
            int rev='z'-c+1;
            sum+=rev*pos;
            pos++;
        }
        return sum;
    }
}
```
