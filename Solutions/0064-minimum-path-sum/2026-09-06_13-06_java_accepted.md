## Solution

```java
class Solution {
    public int minPathSum(int[][] g) {
        int n=g[0].length;
        int m=g.length;
        int dp[][]=new int[g.length][g[0].length];

        dp[0][0]=g[0][0];
        for(int i=1;i<n;i++)
        {
            dp[0][i]=dp[0][i-1]+g[0][i];
        }
        for(int j=1;j<m;j++)
        {
            dp[j][0]=dp[j-1][0]+g[j][0];
        }

        for(int i=1;i<m;i++)
        {
            for(int j=1;j<n;j++)
            {
                dp[i][j]=Math.min(dp[i-1][j],dp[i][j-1])+g[i][j];

            }
        }
       return dp[m-1][n-1];
    }
}
```
