## Solution

```java
class Solution {
    public int minMoves2(int[] nums) {
     Arrays.sort(nums);
     int med=nums[nums.length/2];
     int m=0;
     for(int i:nums)
     m+=Math.abs(i-med);

     return m;
    }
 
}
```
