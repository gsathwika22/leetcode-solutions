## Solution

```java
class Solution {
    public String[] createGrid(int m, int n) {
        String g[]=new String[m];
        for(int i=0;i<m;i++)
        {
            StringBuilder sb=new StringBuilder();
            for(int j=0;j<n;j++)
            {
                if(i==0 || j==n-1)
                sb.append('.');
                else
                sb.append('#');
            }
            g[i]=sb.toString();
        }
        return g;
    }
}
```
