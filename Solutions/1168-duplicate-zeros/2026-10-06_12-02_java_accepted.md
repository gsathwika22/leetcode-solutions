## Solution

```java
class Solution {
    public void duplicateZeros(int[] arr) {
        int c=0;
        // int ans=new int[arr.length];
        for(int i=0;i<arr.length;i++)
        {
            if(arr[i]==0)
            {
                c++;
            }
        }
       int i=arr.length-1;
       int j=arr.length+c-1;
       while(i>=0)
       {
        if(j<arr.length)
        arr[j]=arr[i];
        if(arr[i]==0)
        {
        j--;
        if(j<arr.length)
        arr[j]=0;
       }
       
       i--;
       j--;
    }}
}
```
