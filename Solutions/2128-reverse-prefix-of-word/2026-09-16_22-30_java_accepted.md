## Solution

```java
class Solution {
   
    public String reversePrefix(String word, char ch) {
      
        Stack<Character> st=new Stack<>();
        StringBuilder sb=new StringBuilder();
        for(char c:word.toCharArray())
        {
                st.push(c);
                if(c==ch)
                {
                while(!st.isEmpty())
                {
                    sb.append(st.pop());
                }
                int x=word.indexOf(ch);
                sb.append(word.substring(x+1));
                return sb.toString();
                }
                }
                return word;
    }
}
```
