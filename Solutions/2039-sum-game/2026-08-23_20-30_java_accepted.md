## Solution

```java
class Solution {
    public boolean sumGame(String num) {
        int n=num.length()/2;
        int l=0,r=0;
        for(int i=0;i<num.length();i++)
        {
            char ch=num.charAt(i);
            int v;
            if(ch=='?')
            v=9;
            else 
            v=2*(ch-'0');
            if(i<n)
            l+=v;
            else
            r+=v;
        }
        return l!=r;
    }
}
```
